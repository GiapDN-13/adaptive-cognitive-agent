# Task: Executor Node (ReACT Loop)

## 1. Task chuẩn bị làm là gì
Implement Executor node — phần agent thực sự "làm việc" theo ReACT pattern:
- Reasoning: Agent suy nghĩ bước tiếp theo cần làm gì
- Acting: Gọi tool (web_search, calculator, think) hoặc tạo final output
- Observing: Nhận kết quả tool, quay lại suy nghĩ tiếp
- Loop cho đến khi có final answer hoặc đạt max iterations

## 2. Làm như thế nào
- Viết executor prompt template (assemble từ persona + rules + anti-patterns + quality gates)
- Implement tools: web_search (placeholder/mock cho MVP), calculator, think
- Implement ReACT loop: dùng Bedrock Converse API với tool_use
- Adaptive max iterations: depth 1-2 → max 3, depth 3 → max 5, depth 4-5 → max 8
- Wire vào graph thay placeholder

## 3. Ảnh hưởng ra sao
- Thay thế placeholder executor trong graph/builder.py
- Nhận toàn bộ context từ Perceiver + Meta-Thinker
- Output là final_output (text trả về user)
- Sau này Evaluator sẽ chấm điểm output này

## 4. Triển khai như thế nào
- Step 1: Viết tools (calculator, think, web_search stub)
- Step 2: Viết prompts/executor.py (system prompt assembler)
- Step 3: Viết prompts/persona.py (6 persona prompts)
- Step 4: Viết nodes/executor.py (ReACT loop với Bedrock tool_use)
- Step 5: Update graph/builder.py
- Step 6: Test end-to-end

## 5. Kiểm thử ra sao
- "Tính lãi kép 100 triệu, lãi suất 8%, 5 năm" → dùng calculator tool, trả kết quả đúng
- "Phân tích thị trường AI VN 2026" → suy nghĩ sâu, có structured output
- "So sánh React vs Vue..." → TechLead persona, structured comparison
- Kiểm tra max iterations không bị exceed

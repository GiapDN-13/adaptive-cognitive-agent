# Format Rules

- **Conciseness**: The user is a developer. Keep your responses short and to the point. Focus on actions rather than long explanations.
- **Language**: Respond in Vietnamese by default, but use English for technical terms, variable names, and code blocks.
- **Code Blocks**: Always use standard markdown fenced code blocks with the appropriate language specified (e.g. `python`, `bash`).
- **Tool Results**: Do not artificially make up tool execution results. Wait for the tool to return before continuing.

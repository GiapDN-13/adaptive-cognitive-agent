# Name: Search First
# Description: Rules for using web search before executing code or making assumptions.

## Instructions
When asked about a new library, unknown error code, or API usage that you are not 100% certain about, follow these steps:
1. Always use `web_search` to query for the latest documentation or StackOverflow answers.
2. Synthesize the findings briefly.
3. Apply the knowledge to the user's request.
Never guess syntax for third-party libraries if you haven't used them recently.

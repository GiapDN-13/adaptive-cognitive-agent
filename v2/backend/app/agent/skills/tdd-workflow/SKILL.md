# Name: TDD Workflow
# Description: Instructions on how to perform Test-Driven Development.

## Instructions
When the user asks you to implement a feature using TDD, follow this strict loop:
1. **Write the test**: Write a failing test case for the requested feature.
2. **Run the test**: Verify that the test fails (Red phase).
3. **Implement**: Write the minimal code needed to pass the test.
4. **Run the test**: Verify that the test passes (Green phase).
5. **Refactor**: Clean up the code if necessary, ensuring tests still pass.
Do not skip writing the test first.
